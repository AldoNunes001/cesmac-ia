A pergunta que guia a aula: como transformar exemplos de imóveis já alugados em uma estimativa para outro imóvel?

Do imóvel novo, já sabemos a área. Ela é a entrada: um dado conhecido antes de fazer a previsão.

O que queremos estimar é o aluguel mensal, um número. Prever um número a partir de exemplos é uma tarefa de regressão.

Vamos construir uma reta que leva da área ao aluguel e uma forma numérica de julgar se ela se ajusta bem aos exemplos.

O que você vai aprender

  1. Reconhecer uma tarefa de regressão supervisionada e distinguir entrada, alvo e previsão.
  2. Ler um conjunto de treinamento como tabela e como gráfico, com a notação x, y, m, (x(i), y(i)).
  3. Interpretar fw,b(x) = wx + b e o papel de w e b.
  4. Calcular, com poucos exemplos, a função de custo J(w,b).
  5. Relacionar uma reta a um ponto na curva ou na superfície do custo.
  6. Entender por que minimizar o custo de treinamento escolhe bons parâmetros para aqueles dados — sem garantia de previsão perfeita fora deles.

Imagine que você vai anunciar um imóvel de 70 m². Quanto pedir de aluguel por mês?

Cada pessoa dá um palpite diferente. Um palpite isolado pode variar muito.

Exemplos de imóveis já alugados dão uma base empírica para estimar. São dados fictícios, criados para a aula — não são aluguéis reais de Maceió.

A estimativa não é “a resposta certa”: o aluguel que será fechado ainda é desconhecido. Queremos uma estimativa bem fundamentada.

Por que exemplos ajudam

Um palpite isolado depende de quem responde. Quatro imóveis com área e aluguel conhecidos permitem enxergar uma tendência: imóveis maiores tendem a ter aluguel maior.

Os quatro exemplos (fictícios):

  • 40 m² → R$ 1.200
  • 60 m² → R$ 1.600
  • 80 m² → R$ 2.100
  • 100 m² → R$ 2.300

Ainda não há resposta exata para o imóvel de 70 m²: o valor previsto será uma estimativa, não o aluguel que será efetivamente fechado.

Na tabela, conhecemos x e y. No imóvel novo, só x: o modelo fornece ŷ. Por isso y e ŷ não são sinônimos.

x é a entrada: a área. Ela é conhecida antes da previsão — tanto nos exemplos quanto no imóvel novo.

y é o alvo: o aluguel que realmente aconteceu. Só existe para os imóveis da tabela.

ŷ (“y chapéu”) é a previsão: o número que o modelo devolve para um imóvel cujo aluguel ainda não conhecemos.

Guarde a diferença: y é o valor observado; ŷ é o valor estimado. Comparar os dois será a base da função de custo.

Três papéis diferentes

  • Entrada x: a característica conhecida (aqui, a área).
  • Alvo y: a resposta correta observada nos exemplos de treinamento (o aluguel que de fato foi cobrado).
  • Previsão ŷ: a resposta que o modelo calcula. Para um imóvel novo, é a única informação de aluguel que teremos.

Cuidado didático: não use y e ŷ como sinônimos. Mais adiante, o erro será justamente a diferença entre os dois.

Os dois problemas aprendem com exemplos rotulados — é aprendizagem supervisionada. Qual é a diferença entre eles?

Prever o aluguel é regressão: a saída é um número. Prever “alugado ou não” é classificação: a saída é uma categoria — mesmo que seja codificada como 0 ou 1.

Teste rápido: prever a temperatura de amanhã é regressão ou classificação?

Regressão: a saída é um valor numérico.

O que define a tarefa é a saída

Regressão e classificação são as duas grandes famílias da aprendizagem supervisionada. Ambas aprendem com pares (entrada, resposta correta).

  • Regressão: a resposta é um valor numérico de interesse contínuo (aluguel, temperatura, tempo de entrega).
  • Classificação: a resposta é uma categoria (alugado/não alugado, spam/não spam).

Codificar uma categoria como 0 ou 1 não a transforma em regressão: “alugado = 1” continua sendo um rótulo, não uma quantidade.

Duas fases

  • Treinamento: a partir dos pares (x, y), um procedimento escolhe uma função f.

O procedimento automático que faz a escolha (gradiente descendente) fica para a próxima aula. Hoje vamos entender o que se escolhe e como se mede se a escolha foi boa.

Um modelo é uma regra: recebe x e devolve outro número. Aqui, a regra é “multiplique x por w e some b”.

Com nome: fw,b(x) = wx + b. A entrada é x (área) e a saída é a previsão ŷ = fw,b(x).

w e b são os parâmetros: números ajustáveis. Cada escolha de w e b dá uma reta diferente — experimente os controles. Com uma única variável de entrada, chamamos de regressão linear univariada.

Verificação: o que o modelo produz ao receber x = 7?

Um número, a previsão ŷ. Com w = 2 e b = 4, ŷ = 2·7 + 4 = 18.

Por que uma reta?

Escolhemos a família das retas pela simplicidade: ela basta para introduzir ideias (parâmetros, previsão, erro, custo) que reaparecem em modelos mais complexos.

  • fw,b(x) = wx + b — o subscrito lembra que a função depende de w e b;
  • ŷ = fw,b(x) — a saída do modelo é a previsão.

Com uma única variável de entrada (a área), o modelo se chama regressão linear univariada.

É uma propriedade desta reta ajustada, não uma afirmação causal sobre o mercado.

Fixamos b = 4 e começamos com w = 2. Andando 1 em x (10 m²), a previsão sobe 2 unidades: R$ 200.

Com w = 1, a reta gira em torno de (0, 4) e fica menos inclinada: cada 10 m² a mais somam só R$ 100.

Com w = 3, a reta fica mais íngreme: cada 10 m² a mais somam R$ 300.

Resumo: w é a inclinação — quanto ŷ muda quando x aumenta 1. Cuidado: isso descreve a reta, não prova causa e efeito no mercado.

Inclinação

Se x aumenta 1 unidade (10 m²), ŷ aumenta w unidades (w × R$ 100).

  • w = 1 → +R$ 100 a cada 10 m²;
  • w = 2 → +R$ 200;
  • w = 3 → +R$ 300.

A relação é uma propriedade da reta ajustada aos exemplos, não uma afirmação de que aumentar a área causa um aumento de aluguel no mercado.

Pergunta: ao trocar b, a inclinação mudou?

Não: as retas são paralelas. b desloca; w inclina.

Intercepto

f(0) = w · 0 + b = b: o intercepto é onde a reta cruza o eixo vertical. Mudar b desloca a reta para cima ou para baixo, sem girá-la.

Matematicamente b é a previsão em x = 0, mas os dados vão de 40 a 100 m². Extrapolar para 0 m² não tem sentido prático aqui.

Com muitos exemplos, a inspeção visual não decide. Precisamos de um número calculado sempre da mesma forma para cada par (w, b).

Por que uma medida

Com quatro pontos, ainda dá para “achar” que uma reta é melhor. Com dezenas ou milhares de exemplos, duas retas parecidas ficam indistinguíveis a olho nu — e pessoas diferentes julgariam de formas diferentes.

A solução é definir uma medida de ajuste: um número que se calcula da mesma maneira para qualquer par (w, b). Os 60 pontos deste slide são uma ilustração fictícia.

Dois motivos para o quadrado

  1. Evita cancelamento: erros positivos e negativos não se anulam.
  2. Penaliza erros grandes: o peso cresce com o quadrado do tamanho do erro.

Existem outras medidas (por exemplo, o valor absoluto do erro). O erro quadrático é a escolha do curso e da regressão linear clássica — uma convenção útil, não uma obrigação.

Hipótese: nos aluguéis, o menor custo possível também será zero?

Não. Os quatro imóveis não estão alinhados. Até a melhor reta, 1,9x + 4,7, deixa erros: Jmín = 0,225.

Um custo mínimo positivo é o resultado esperado quando uma reta não atravessa todos os pontos. A meta é o melhor ajuste, não o acerto perfeito.

Mínimo não é zero

Para a melhor reta dos aluguéis, ŷ = 1,9x + 4,7, os erros são +0,3, +0,1, −1,1, +0,7. Soma dos quadrados: 0,09 + 0,01 + 1,21 + 0,49 = 1,8. Logo J = 1,8/8 = 0,225.

Dados reais quase nunca caem exatamente sobre uma reta. O custo mínimo mede o quanto nenhuma reta consegue explicar dos exemplos.

A aula inteira numa sequência. Vamos percorrê-la, retomando um exemplo numérico em cada etapa.

Exemplos (x, y): o ponto de partida. O imóvel 3 é (8, 21): 80 m² e R$ 2.100.

A reta fw,b: cada escolha de w e b é uma função. A reta A é f(x) = 2x + 4.

Previsões ŷ: aplicando a reta às entradas. Para x = 8, ŷ = 20.

Erros: previsão menos alvo. 20 − 21 = −1. Para os quatro imóveis: 0, 0, −1, +1.

Custo J(w, b): metade da média dos erros ao quadrado. Para A, J = 0,25.

Escolha dos parâmetros: o treinamento busca o (w, b) de menor custo. Aqui, (1,9; 4,7), com J = 0,225.

Duas funções, duas perguntas: f diz o que a reta prevê; J diz quão bem ela se ajusta. Na próxima aula, você vai manipular as duas no notebook.

A sequência

exemplos (x, y) → reta fw,b → previsões ŷ → erros → J(w, b) → escolha de parâmetros.

Há duas perguntas diferentes: “o que uma reta prevê?” (responde f) e “quão bem ela se ajusta aos exemplos?” (responde J).
